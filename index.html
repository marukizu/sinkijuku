ビラの一問、解けましたか？

答えだけでなく、解くときの考え方の順番まで書きました。信稀塾の面談では、この「手が動く順番」を1問ずつ言葉にしていきます。

高校1年生
y = −2(x−3)2+7
の最大値を求めよ。
1

式の形を読む

すでに平方完成された y = a(x−p)2+q の形。ここでは a = −2、頂点は (3, 7) と一目で読み取れます。

2

a の符号で上下を決める

a = −2 < 0 なので、グラフは上に凸。上に凸の放物線は、頂点で最大値をとります（最小値はなし）。

3

不等式で確かめる

(x−3)2 ≧ 0 だから −2(x−3)2 ≦ 0。よって y ≦ 7 で、等号は (x−3)2 = 0、つまり x = 3 のとき。

ANSWER

x = 3 のとき、最大値 7

つまずきやすい点：「最大値」を聞かれているのに x = 3 と答えてしまう。求められているのは y の値です。

高校2年生
9log35
の値を求めよ。
1

底をそろえる

指数の底は 9、対数の底は 3。9 = 32 と書き換えて、両方を 3 に統一するのが出発点です。

2

指数法則で1つの累乗に

9log35 = (32)log35 = 32log35。(am)n = amn を使っただけです。

3

係数を対数の中へ

2log35 = log352 = log325。対数の前の数は、真数の指数に移せます。

4

alogaM = M を使う

3log325 = 25。「底と対数の底が同じなら、真数がそのまま残る」——ここまで来れば一瞬です。

ANSWER

25

つまずきやすい点：log35 を計算しようとして手が止まる。値を出さずに、指数法則と対数法則で形を変えるだけで解けます。

この解き方の「順番」を、あなたの選んだ単元で2週間まるごと。

代表紹介

教えるのは、その道を歩いた先輩。

丸田 稀月

信稀塾 代表 ／ 八尾高校OB・大阪公立大学

八尾高校で陸上部の長距離選手として最後まで走り切り、部活引退後に受験勉強へ。第一志望の大阪公立大学に1.75点差で届かず、浪人を選択。翌年、宅浪で合格しました。

個別指導塾での指導では、80%以上の生徒の定期テストを20点以上アップ。「自称進学校」の内側にいたからこそ、勉強習慣の重さを知っています。生徒とともに全力で志望校に向き合い、合格させる——それが信稀塾の理念です。

よくある質問

不安を、そのままにしないで。

2週間の無料体験は、本当に無料ですか？
はい。入会金・教材費も含めて費用は一切かかりません。体験後に続けるかどうかも自由にお決めいただけます。
体験ではどの単元を扱いますか？
数学または英語から、生徒本人に1単元を選んでいただきます（数学Ⅰ・A／Ⅱ・B、英文法、英単語・語彙、英語長文など）。到達目標は共通テストで7割取れるレベルです。決めきれない場合は初回面談の自己分析で一緒に選びます。
無料受験相談は塾に入らなくても受けられますか？
受けられます。八尾高校76期生OBがオンラインで対応します。入塾のご意思は不要で、相談だけで終わっても構いません。ご予約は公式LINEからお願いします。
八尾市以外に住んでいても受講できますか？
できます。オンラインプランなら全国どこからでもコーチングを受けられます。自習室の利用をご希望の方は、八尾市の校舎をご利用ください。
夏期講習などで追加費用はかかりますか？
一切かかりません。信稀塾は追加費用のない定額制です。表示の月謝以外の費用は発生しません。
成績や偏差値が高くなくても大丈夫ですか？
もちろんです。信稀塾は「勉強習慣がまだ身についていない」生徒こそ対象です。今の状況から逆算し、無理のない計画で伴走します。
保護者は子どもの様子を知れますか？
はい。自習室の入退室、学習の進捗、志望校、合格可能性、ご家庭での接し方などを毎週レポートでお届けします。
